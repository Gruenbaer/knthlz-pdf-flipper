# Security

Report security issues through this repository's **Security → Report a vulnerability**.
Do not put exploit PDFs, credentials, private document links or live signed URLs in
public issues. Provide the affected version, prerequisites, a minimal reproduction
and impact. A private report is reviewed before a public advisory is coordinated.

The latest public beta is the supported prerelease line. A beta has not undergone
an independent security audit. Hosting must keep TYPO3, PHP, Ghostscript and the
configured image processor patched. The project does not promise a response SLA.

Preview requests require a signed, source-bound token and a public FAL PDF. They
are not an access-control mechanism for a confidential publication. Selected-page
views and hidden download buttons do not remove access to the original PDF.
