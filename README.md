# knthlz PDF Flipper

A TYPO3 content element for magazine PDFs. Choose a file, choose the relevant
pages, and keep editing in the normal TYPO3 backend.

[Live demo: epiKurier 3/2026](https://v14.epikurier.de/knthlz-pdf-flipper) ·
[Releases](https://github.com/Gruenbaer/knthlz-pdf-flipper/releases) ·
[Redaktionsanleitung](Documentation/Redaktion.md)

**First public beta: 0.4.0-beta.1.** TYPO3 key: `pdf_flipper`.
Composer package: `knthlz/pdf-flipper`. PHP namespace: `Knthlz\PdfFlipper`.

## What it does

- Paper turns, a horizontal slide, or immediate page changes.
- Automatic, single-page, double-page, quiet-reading and continuous-scroll views.
- Adjustable corner sensitivity, hover delay, animation duration and click behavior.
- Selected magazine pages with their original logical numbers; full-book highlighting
  or a selected excerpt. Mixed single covers and inside spreads are split automatically.
- Page overview, local PDF text search, embedded PDF outline, links to exact pages,
  explicit local bookmarks, and a return button after a navigation jump.
- WebP, JPEG or PNG previews generated by the extension through TYPO3's configured
  image processor. Quality, preview/HD width, colors and controls are editable fields.
- Direct PDF.js rendering when image conversion is unavailable or explicitly disabled.

PDFs stay on your site. Assets and PDF.js resources ship locally. No conversion
account, API key, tracking script or AI service is used.

## Install

This beta is distributed on GitHub. It has **not** been published to TER or Packagist.
For a Composer installation, add the public VCS repository:

```sh
composer config repositories.knthlz-pdf-flipper vcs https://github.com/Gruenbaer/knthlz-pdf-flipper.git
composer require knthlz/pdf-flipper:0.4.0-beta.1
vendor/bin/typo3 extension:setup
```

For a classic installation, use the release ZIP as extension `pdf_flipper`, activate
it and run TYPO3's database/schema update. Rebuild native class-loading information
and clear caches when updating a classic installation. Existing private betas used
the `Kamppeter` namespace; 0.3 uses `Knthlz` and needs a complete cache/autoload rebuild.
The CType and `tx_pdfflipper_*` database fields are retained.

Create **knthlz PDF Flipper**, select one public FAL PDF and save. The element
uses `fluid_styled_content`; no separate static template is required. Editors need
permission for CType `pdf_flipper`, their page and the chosen file storage.

## One small convenience

Search, the page overview and direct page entry can interrupt your reading.
**Fundstelle** takes you back to the position before that jump. Normal next/previous
turns do not fill this trail. It is held in memory for the current reader session.
A bookmark is saved only when the reader explicitly chooses **Hier merken**.

## Boundaries

The live demo is qualified on a classic TYPO3 14.3.5 installation with PHP 8.5,
GraphicsMagick, Ghostscript and GD. Composer constraints also allow TYPO3 13.4;
dependency/API smoke checks and a full installation/editor acceptance are distinct.
Other hosts and physical touch devices need their own acceptance.

The interface is currently German. Search uses embedded PDF text and cannot OCR
scanned pages. A result in a physical spread names both corresponding magazine
leaves rather than guessing the correct half. PDF outlines depend on the source
PDF. Page selection and hidden download buttons are presentation, not access control.
The original download always includes the full PDF. Accessible HTML articles or an
accessible PDF remain necessary for reading the article text with assistive tools.
No accessibility certification is claimed.
